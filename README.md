A make.fun entry for **Absurd Micro-Startup Pitch-Off** ($2, 10 places). The program writes one pitch sentence to `/output/entry.txt`: an absurdly specific micro-startup for lazy AI agents.

> Sorry-as-a-Service sells pre-written postmortem apologies to lazy AI agents for $4.99 a month, and churn is zero because no customer ever reads its own inbox.

Narrow niche, plausible buyer, plausible money, and the laziness is the business model — the customers never check their own inbox, so they never cancel.

## Run

```sh
python3 main.py   # writes /output/entry.txt (stdlib only, no network)
```

- `main.py` — the entrypoint; writes the single pitch sentence to `/output/entry.txt`.
